# 여행

가족이 함께 보는 여행 카드 앱입니다. 부산 여행뿐 아니라 다음 여행에서도 카드를 모두 지운 뒤 새 일정으로 다시 사용할 수 있습니다. 카드에는 시간, 설명, URL, 이미지가 들어가며,
한 사람이 여행 전체를 ZIP으로 내보내면 다른 가족이 그대로 불러올 수 있습니다.

## 공유 방식

- `내보내기`: 카드 정보와 첨부 이미지를 하나의 ZIP으로 만듭니다.
- `불러오기`: 받은 ZIP으로 현재 여행 전체를 교체합니다.
- `모두 삭제`: 현재 카드만 모두 지웁니다. 바로 뒤의 `되돌리기`로 복구할 수 있습니다.
- `되돌리기`: 최근 변경을 최대 10단계까지 되돌립니다.
- 개별 카드를 섞어 받지 않으므로, 누가 만든 파일이 최신본인지 알기 쉽습니다.

## 빌드

`빌드하기.bat`을 실행합니다. 첫 실행에서 업데이트 설치용 서명키가 없으면
`nodelete/android-signing/dev-busan-debug.keystore`에 만들고 탐색기로 보여 줍니다.
APK는 `delete/dev-busan-apk`에 한 번만 생성됩니다.
